모두의 게임

AI로 만든 나만의 웹 게임 주소를 올리면 바로 여기에 등록됩니다. 승인도 로그인도 필요 없습니다.

내가 만든 게임의 주소만 올려 주세요. 올린 글은 고치거나 지울 수 없습니다.

내 게임 올리기

게임 이름과 주소만 있으면 됩니다. 올리면 바로 아래 목록에 나타납니다.

클로드·ChatGPT 공유 링크나 GitHub Pages처럼 https:// 로 시작하는 공개 주소를 넣어 주세요.

💡 게임 주소(https://...)는 어떻게 만드나요?
  1. 클로드(Claude) / ChatGPT로 만든 경우

    게임 화면에서 공유(Share) → 공개 링크 복사를 누르고, 나온 주소를 그대로 붙여넣으세요.

  2. HTML 파일로 만든 경우

    무료로 올릴 수 있는 GitHub Pages나 Netlify Drop에 파일을 올린 뒤 나온 https:// 주소를 넣으세요. 내 PC의 파일 경로(file://)나 로그인해야 열리는 비공개 링크는 다른 사람이 플레이할 수 없습니다.

  3. 등록하면

    승인 없이 바로 아래 카드에 등록되고, 누구나 이 사이트 안에서 바로 플레이할 수 있습니다.

등록하면 바로 공개됩니다. 연속 등록은 15초 뒤에 가능합니다.

게임은 이 사이트 안에서 바로 열립니다. 주소는 https:// 로 시작해야 합니다. 올라온 게임은 다른 사람이 만든 외부 사이트이며, 이 사이트는 내용을 미리 검사하지 않습니다. 문제가 있는 게임은 🚩 신고해 주세요.
